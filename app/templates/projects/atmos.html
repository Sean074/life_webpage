ATMOS

{{ project.tagline }}

ATMOS is a small standard-atmosphere and air-data tool. It interpolates a tabulated atmospheric model, converts between Mach and true, calibrated and equivalent airspeed (subsonic and supersonic, using the Rayleigh pitot formula above Mach 1), and draws speed-altitude charts with optional VMO/MMO-style envelope boundaries. The desktop version is a terminal program; this page runs the same engine (source). Nothing you enter is stored.
